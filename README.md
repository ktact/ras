# ras
A toy x86-64 assembler that reads Intel-syntax assembly and writes ELF64 relocatable object files.

## Goal
Assemble everything that [pugcc](https://github.com/ktact/pugcc) emits when it compiles itself, producing object files byte-identical to those generated by GNU as.

## Usage
```
cargo build
./target/debug/ras -c input.s -o output.o
```

## Testing
```
cargo test
```
The integration tests assemble each file in `tests/inputs/` with both `gcc` and ras and compare the resulting object files, so `gcc` must be installed.
